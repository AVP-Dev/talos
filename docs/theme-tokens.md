# Theme Tokens — Scope Note

TALOS is a CLI-first application, so CSS design tokens are outside the current product architecture. This file is retained from Agent Starter Kit as a reference only. Use its design-token guidance only if a separate graphical interface is approved for TALOS.

All documentation and UI text, if a graphical interface is later added, must remain in English. UI styling decisions should then be defined in a dedicated design specification rather than applied to CLI components.
