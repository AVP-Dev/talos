# TALOS v0.1.2 — Native workspace preview

This incremental release introduces the persistent terminal workspace without replacing the existing managed cockpit.

- Original Writer and Critic CLI terminals run inside tmux; reconnecting keeps the existing panes.
- A compact status pane provides settings, the separate managed cockpit, and columns/stacked layouts.
- First-run role discovery and F2 settings select installed CLI executables. Models and credentials remain in the original CLI.
- Explicit single-role replacement preserves other terminal processes. Exit the selected CLI first.
- Updated README and operator guide include actual startup screenshots of Codex and Claude Code before authentication.

The native workspace is a **manual preview**, not an automatically coordinated native-agent workflow. Do not run managed tasks concurrently with manual editing. Authenticated provider execution and actual SSH disconnect/reconnect still require acceptance.

## Install or upgrade

Install the matching archive and SHA-256 file from this release. Homebrew users can upgrade after the tap is updated. Run `talos --version` to confirm `0.1.2`.

With tmux and installed coding CLIs, run `talos attach` in a Git project with an initial commit. Use `talos tui` to open the existing managed cockpit.

## Verification

The native workspace baseline passed Rust formatting, Clippy, tests, release builds, and real tmux layout and process-reuse acceptance on macOS and Linux. Provider sign-in and remote SSH acceptance are not covered by these checks.
